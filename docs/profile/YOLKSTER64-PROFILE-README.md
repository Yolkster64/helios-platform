- **HELIOS Control** — product/control monorepo, AIHub, agents, MCP, automation, Azure, Windows security, recovery, and policy.

## Design principles

- local-first, cloud-boosted;
- one canonical source of truth;
- WinUI 3 only for active desktop UI;
- plan and `what-if` before apply;
- managed identity and workload federation instead of stored client secrets;
- provider-neutral AI contracts;
- human approval for consequential actions;
- evidence, provenance, rollback, and test gates before promotion.

The profile repository contains presentation material only. Product code remains in the canonical repositories.
